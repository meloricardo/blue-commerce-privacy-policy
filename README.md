# Política de privacidade do Blue Commerce

Página pública da política de privacidade do aplicativo Blue Commerce (pacote `ascblue.bluecommerce`), exigida pelo Google Play.

- Conteúdo: [`index.html`](index.html), servido pelo GitHub Pages a partir da raiz da branch `main`.
- Endereço publicado: `https://meloricardo.github.io/blue-commerce-privacy-policy/`, que é a URL informada no Play Console em **Conteúdo do app → Política de privacidade**.

## Ao alterar

- A política precisa bater com o formulário de **Segurança dos dados** do app no Play Console. Mudou um, revise o outro.
- Atualize a data de "Última atualização" no topo da página.
- A estrutura segue a política do Blue Delivery, para as duas dizerem o mesmo sobre controladora, operadora, base legal e transmissão.
- O código do aplicativo fica no repositório privado `blue-mobile`; este repositório é público e não deve receber nada além da política.
